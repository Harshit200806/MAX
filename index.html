THE VISION

Your personal AI command center.

MAX is a JARVIS-inspired assistant concept built around voice interaction, useful shortcuts, and supported desktop actions. This website provides a polished home for the assistant and the AI tools built around it.

The web interface and desktop assistant are separate pieces of software. Features such as launching local applications require a secure connection to the desktop app and are not enabled by this front end alone.
